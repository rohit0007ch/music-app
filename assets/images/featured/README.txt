Featured song artwork for “Dinesh Dalla”
========================================

Place the supplied thumbnail here as either:

  assets/images/featured/dinesh_dalla.jpg
  or
  assets/images/featured/dinesh_dalla.png

Then set FeaturedSong.artworkAssetPath in
lib/data/featured/featured_song.dart to that path
(and keep the folder registered in pubspec.yaml).

Until an image is present, Melora uses the palette
gradient artwork fallback — the app still runs.
